# Validation scope — 30 September 2026

**43 unittest methods passed** in the local Linux build environment, Python 3.13.5, OpenCV 4.13.0, NumPy 2.3.5. Raw output: [test-output.txt](test-output.txt). Tests are rerunnable using `.venv/bin/python -m unittest discover -s tests -v`.

Eight of these methods cover model-file/download guards with fabricated data; they do not execute MediaPipe.

No human-image dataset is bundled. The example outputs were actually generated by the code from synthetic inputs. These results do not establish accuracy on a webcam, benchmark superiority, or fitness for medical, driving, privacy or security decisions. There are no deliberately skipped tests; native model/camera checks are separate commands, not silently counted passes.

**Not executed in the build environment:** clean installation of the pinned requirements, actual MediaPipe model acquisition or inference (where applicable), webcam permissions/capture/UI, macOS and Python 3.14 execution, public GitHub publication or remote CI. Network access for package/model installation was unavailable. No model-weight bytes are included.

Before calling this repository camera-verified, record the real environment and commands, use only your own/consenting subject, check normal and failure cases, and preserve the limitations. The application tests can pass without a usable MediaPipe installation; a unit-test pass alone is insufficient. For the scanner, verify a real local photo and inspect the boundary; for motion, verify a stationary real camera and changing illumination.
